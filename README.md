<h1 align="center">MelCat for Windows</h1>

<p align="center">Let Mel play with your mouse.</p>

[![CI](https://github.com/irobson/melcat-win/actions/workflows/ci.yml/badge.svg)](https://github.com/irobson/melcat-win/actions/workflows/ci.yml)

A gentle, scheduled mouse jiggler for the Windows system tray, written in native Rust. The Windows sibling of [MelCat for macOS](https://github.com/irobson/melcat), with the same features.

Work in progress: the first release is being built. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
